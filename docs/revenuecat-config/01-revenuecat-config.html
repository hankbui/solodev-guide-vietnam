Bước 4

Kết nối App Store & Google Play với RevenueCat

4.1 Kết nối App Store

Lấy App-Specific Shared Secret

App Store Connect → My Apps → chọn app → App Information → copy App-Specific Shared Secret.

Dán vào RevenueCat

RevenueCat Dashboard → Project → App Store Connect → Configure → paste Shared Secret → Save.

4.2 Kết nối Google Play

Tạo Service Account

Google Play Console → Setup → API Access → Create Service Account → làm theo hướng dẫn → lên Google Cloud Console → tạo JSON key.

Upload JSON lên RevenueCat

RevenueCat Dashboard → Project → Google Play → Configure → upload file JSON → Save.

Bước 6

Tích hợp SDK RevenueCat

6.1 Cài đặt

React Native / Expo:

npm install react-native-purchases
npx pod-install

iOS (Swift):

// Podfile
pod 'Purchases', '~> 7.0'

Android (Kotlin):

// build.gradle
implementation "com.revenuecat.purchases:purchases:7.0.0"

Flutter:

flutter pub add purchases_flutter

6.2 Cấu hình SDK

import Purchases from 'react-native-purchases';

// App startup
await Purchases.configure({
  apiKey: 'public_ios_key',   // Public key từ RC Dashboard
  appUserID: userID,           // User ID của bạn (optional)
});

6.3 Lấy Offerings & Purchase

// Lấy offerings
const offerings = await Purchases.getOfferings();
if (offerings.current !== null) {
  const monthly = offerings.current.monthly;
  const yearly = offerings.current.yearly;
}

// Purchase
const { customerInfo } = await Purchases.purchasePackage(monthly);

// Restore purchases
const restore = await Purchases.restorePurchases();

6.4 Lắng nghe thay đổi

Purchases.addCustomerInfoUpdateListener((customerInfo) => {
  const isPremium = customerInfo.entitlements.active['premium'] !== undefined;
  // Cập nhật UI — mở/tính năng premium
});
⚠️ Phân biệt API Key: Public key (prefix public_) dùng trong client SDK. Secret key (prefix sk_) chỉ dùng ở backend — không bao giờ nhúng vào app.

7.1 Tạo Webhook

TrườngVí dụ

Authorization HeaderBearer your_secret_token
EventsSelect all

7.2 Webhook Events quan trọng

EventKhi nàoBackend cần làm
INITIAL_PURCHASEUser mua lần đầuCấp quyền
RENEWALGia hạn tự độngGia hạn quyền
CANCELLATIONUser huỷLog — sẽ mất quyền khi hết hạn
EXPIRATIONHết hạnThu hồi quyền
PRODUCT_CHANGEUpgrade/downgradeCập nhật quyền

7.3 Xử lý Webhook (Node.js)

app.post('/revenuecat/webhook', async (req, res) => {
  const event = req.body.event;

  switch (event.type) {
    case 'INITIAL_PURCHASE':
    case 'RENEWAL':
      await grantPremiumAccess(event.app_user_id);
      break;
    case 'EXPIRATION':
      await revokePremiumAccess(event.app_user_id);
      break;
  }
  res.status(200).send('OK');
});

Testing với Sandbox & StoreKit

8.1 Sandbox Testing — Apple

App Store Connect → Users and Access → Sandbox Testers → + → tạo account → trên device vào Settings → App Store → Sandbox Account → sign in → mua IAP (sandbox, không tính phí).

8.2 Sandbox Testing — Google Play

Google Play Console → Setup → License Testing → thêm test email → add test account trên device → mua subscription.

8.3 StoreKit Configuration (Xcode — local testing)

Không cần network, test IAP ngay trên simulator:

Xcode → File → New → File → StoreKit Configuration
→ Thêm product IDs khớp với RevenueCat
→ Scheme → Edit Scheme → Options → StoreKit Configuration → chọn file

8.4 Testing Checklist

  • Sandbox purchase iOS ✓
  • Sandbox purchase Android ✓
  • Subscription renewal ✓
  • Subscription cancellation ✓
  • Restore purchases ✓
  • Offerings hiển thị đúng ✓
  • Entitlements active sau purchase ✓
  • Webhook nhận events ✓
  • Upgrade/Downgrade ✓
  • Grace period ✓
